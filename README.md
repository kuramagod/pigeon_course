# Список задач API

## API контракт

### GET /tasks

Список задач с фильтрацией

**Query-параметры**

| Имя | Тип | Обяз. | Описание |
|-----|-----|-------|----------|
| `is_complete` | bool | нет | Фильтр статуса задачи |

**Ответ `200`**
```json
{
  "items": [
    {
      "id": "100",
      "title": "Имя задачи",
      "description": "Описание задачи",
      "is_completed": false,
      "created_at": "2026-01-15T10:30:00Z"
    },
    ...
  ]
}
```

**Ошибки:** `404`

---

### GET /tasks/{id}

Получить задачу по ID.

**Path-параметры**

| Имя | Тип | Обяз. | Описание |
|-----|-----|-------|----------|
| `id` | string | да | ID задачи |


**Ответ `200`**
```json
{
  "id": "100",
  "title": "Имя задачи",
  "description": "Описание задачи",
  "is_completed": false,
  "created_at": "2026-01-15T10:30:00Z"
}
```

**Ошибки:** `404`

---

### POST /tasks

Создать новую задачу.

**Тело запроса**

| Поле | Тип | Обяз. | Ограничения |
|------|-----|-------|-------------|
| `title` | string | да | 1–200 символов |
| `description` | string | нет | до 2000 символов |
| `is_completed` | bool | нет | по умолчанию `false` |

**Пример запроса**

**Ответ `201`**
```json
{
  "id": "100",
  "title": "Имя задачи",
  "description": "Описание задачи",
  "is_completed": false,
  "created_at": "2026-01-15T10:30:00Z"
}
```

**Ошибки:** `422`

---

### PUT /tasks/{id}

Обновление задачи. 

**Path-параметры**

| Имя | Тип | Обяз. | Описание |
|-----|-----|-------|----------|
| `id` | string | да | ID задачи |

**Тело запроса**

| Поле | Тип | Обяз. | Ограничения |
|------|-----|-------|-------------|
| `title` | string | да | 1–200 символов |
| `description` | string | нет | до 2000 символов |
| `is_completed` | bool | да | - |


**Ответ `200`**
```json
{
  "id": "100",
  "title": "Имя задачи",
  "description": "Описание задачи",
  "is_completed": true,
  "created_at": "2026-01-15T10:30:00Z"
}
```

**Ошибки:** `404`, `422`

---

### DELETE /tasks/{id}

Удалить задачу по ID.

**Path-параметры**

| Имя | Тип | Обяз. | Описание |
|-----|-----|-------|----------|
| `id` | string | да | ID задачи |


**Ответ `204`**

**Ошибки:** `404`

## Как запустить локально

Создать виртуальное окружение
```bash
python -m venv .venv
```

Установка зависимостей
```bash
pip install -r requirements.txt
```

Запуск приложения

`Убедитесь что вы в директории /pigeon_course`

```bash
uvicorn main:app
```
